# Проверка Telegram — 8 ноября 2026

Исправлены выбор языка смешанной речи и отображение источников.

- Telegram передаёт `languageSelection: auto`; `understand` возвращает валидированный `responseLanguage`. Язык применяется до выбора FAQ, перевода и проверки. Playground сохраняет явный выбор языка.
- Точный FAQ в автоматическом режиме проверяется после определения языка и только по исходному вопросу без истории; переписанный запрос не обходит проверку доказательств.
- Источники получают локализованный заголовок и маркированный список. Страница PDF обозначается `стр. N`, `N-бет`, `p. N`.
- Верификатору явно описаны поля доказательства FAQ и совместимые дополнительные сведения в переводах. Генератору документов указано существующее ограничение схемы в 1–5 утверждений.
- В примере JSON этапа понимания поле `responseLanguage` сделано обязательным и для поисковых запросов, и для уточнений. Пропуск поля отклоняется валидатором без выдумывания ответа.
